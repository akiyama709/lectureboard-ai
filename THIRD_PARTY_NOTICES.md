# Third-party notices

The initial scaffold has no bundled third-party model weights, fonts, binary frameworks, or runtime packages.

Development tooling:

- XcodeGen is used to generate the Xcode project and is distributed under its own license.
- GitHub Actions uses official GitHub-hosted runners and the `actions/checkout` action.

Before adding a speech model, language model, font, or binary dependency, document its license, redistribution terms, model-data provenance, privacy behavior, and security update process here.
