# ADR 0006: Adopt the MIT License for the initial repository

- Status: Accepted for the alpha scaffold，pending institutional review before public publication
- Date: 2026-08-29

## Context

The project is intended for public educational and research collaboration. The initial repository needs a concise，widely understood permissive license. The maintainer’s institutional intellectual-property and software-publication obligations must still be checked before the repository is made public.

## Decision

Use the MIT License for the alpha scaffold. Preserve third-party notices and do not include assets，models，fonts，or code whose terms are incompatible with MIT distribution.

## Consequences

Reuse and contribution terms are simple. The license does not replace institutional approval requirements and does not contain an express patent grant. Publication should not proceed until the maintainer has completed the required institutional review.
