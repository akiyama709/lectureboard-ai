# LectureBoard AI macOS版 画面設計書 ver.1.3

## 0．対象環境

本版の実装対象はmacOS 26以降，Apple silicon優先，Microsoft PowerPoint for Macとする．Windows版およびLinux版は，当面の画面設計対象に含めない．

## 1．今回の仕様変更

本版では，音声コマンドを基本操作から外し，講師が特定の命令句を発しなくても自動板書が成立することを必須要件とする．

本アプリは，講師の発話を単純に字幕化するのではなく，PowerPointの内容，講義の前後関係，話し方，反復，説明構造，既に表示した板書を統合し，何を板書すべきかを自律的に判断する．

音声コマンドの一覧やヘルプは講義画面に表示しない．講師が使う操作は，原則として「一時停止」「取消し」「固定」「消去」「ペン優先」の最小限に限る．

## 2．設計原則

### 2.1 ゼロコマンド標準

講師は通常どおり講義するだけでよい．「ここを板書してください」「図にしてください」などの特別な発話は不要とする．

### 2.2 文脈優先

板書判断では，単に「重要」「つまり」などの語を検出するだけではなく，次を総合する．

- 現在のスライドと発表者ノート
- 直前までの発話と板書
- 講義全体の構成
- 新しい定義，対比，因果関係，列挙，結論，例外
- 同じ概念の反復や言い換え
- 発話速度，間，抑揚などの補助情報
- スライドを表示している時間
- ポインタやペンが注目している位置
- スライド上に既に書かれている内容との差分

### 2.3 非介入性

判断に迷う場合，AIは講師に質問せず，直ちに板書もしない．後続の発話を待ち，意味が確定してから追記する．

### 2.4 安定表示

認識途中の文章は学生に見せない．内部の下書き領域で数秒間整理し，意味単位が確定してから描画する．一度確定した板書は，原則として動かさない．

### 2.5 人間優先

講師がペンタブで書き始めた領域は，即座に講師優先領域となる．AIはその領域に重ね書きせず，既存の手書きを消去しない．

## 3．板書判断エンジン

発話の各意味単位について，次の評価を行う．

**板書価値 ＝ 教育的重要性 ＋ スライドとの差分 ＋ 構造化可能性 ＋ 講義全体との関連性 － 重複 － 不確実性 － 必要面積**

### 3.1 板書しやすい内容

| 発話の役割 | 自動板書形式 |
|---|---|
| 新しい概念の定義 | 用語＋短い定義 |
| 三点以上の列挙 | 番号付き箇条書き |
| 原因と結果 | 矢印図 |
| AとBの違い | 二列比較 |
| 過程の説明 | フローチャート |
| 上位・下位概念 | 階層図 |
| 例外や注意 | 小さな囲み注記 |
| 講義の中心的な問い | 問いとして固定 |

### 3.2 原則として板書しない内容

- スライド本文の単純な読み上げ
- 挨拶，雑談，時間調整
- まだ結論が定まっていない言い直し
- 一時的な脱線
- 根拠が不明確な固有名詞，数値，年号
- 既に十分に板書されている内容の反復

### 3.3 文字と図形の選択

AIは内容をまず意味構造として表現し，その後に描画形式を選ぶ．

- 定義，補足，注意は文字中心
- 因果，順序，転換は矢印中心
- 比較は二列または対向配置
- 複数概念の関係は概念マップ
- 時間的推移は横方向フロー
- 階層は上下方向ツリー

自由な画像生成ではなく，編集可能な文字，線，矢印，枠，ノードとして描画する．

## 4．言語設計

### 4.1 入力言語

- 自動判定
- 日本語
- 英語
- 日本語・英語混在

自動判定では，文単位ではなく意味単位ごとに言語を識別する．講義途中で日本語から英語へ切り替わっても，操作は不要とする．

### 4.2 板書出力言語

- 発話と同じ言語
- 常に日本語
- 常に英語
- 日本語主体＋英語専門語
- 英語主体＋日本語補足
- 重要語のみ日英併記
- 全文日英併記

標準設定は「発話と同じ言語，専門語は原語を保持」とする．

### 4.3 言語別レイアウト

日本語では意味の切れ目に基づく改行を優先し，英語では句や節のまとまりを保つ．日英併記では，二重表示で余白を過剰消費しないよう，重要語だけを括弧で併記する設定を標準とする．

## 5．描画スタイル

初版から次の二つを選択可能とする．両者は同じ意味構造を異なる描画器で表現する．

### 5.1 整ったデジタルインク風

- 高い可読性
- 均一に近い線
- 整った文字配置
- 明瞭な矢印と囲み
- オンライン講義に適する

### 5.2 より手書き風

- 適度な線の揺れ
- ペン圧を模した太さの変化
- わずかな文字位置の不均一
- フリーハンド風の矢印と囲み
- 対面講義や対話型講義に適する

個人の筆跡を模倣する機能は初版には含めず，将来機能とする．

### 5.3 共通カスタマイズ

- 文字サイズ
- 文字の太さ
- 行間
- 線幅
- 手書き感
- 図形の整い具合
- 矢印の形
- 強調色
- 描画速度
- 文字と図の比率
- 1枚当たりの板書量

## 7．AI板書と講師の手書きの共存

描画レイヤーを次のように分離する．

1. PowerPoint原画レイヤー
2. AI板書レイヤー
3. 講師ペンレイヤー
4. 一時的なポインタレイヤー

講師ペンレイヤーを最優先とし，AIは講師の線を障害物として扱う．講師がAI板書の近くへ書き込んだ場合，AIは残りの空白へ配置を変更する．

## 8．自動板書の時間設計

### 8.1 二段階処理

**高速処理**では，音声認識と意味単位の仮判定を行う．

**確定処理**では，直後の発話を含めて意味を再評価し，板書するか否か，文字か図か，どこへ配置するかを決定する．

### 8.2 表示原則

- 発話開始直後には書かない
- 意味が確定してから書く
- 一項目ずつ安定して追加する
- 既存板書をむやみに再配置しない
- 新しい説明で誤りが判明した場合のみ，直近項目を静かに訂正する

## 9．個人化

アプリは，講師が行った次の操作をローカルに学習できる．

- 取り消した板書
- 固定した板書
- 手動で加えた内容
- 文字を図に変更した操作
- 1枚当たりの好みの板書量
- 日本語と英語の表記選択

これにより，使用を重ねるほど，講師固有の「何を板書するか」に近づける．外部学習への利用は初期設定で無効とする．

## 10．MVP必須要件

1. 音声コマンドなしで動作すること．
2. 日本語，英語，日英混在を自動認識すること．
3. スライド内容と発話との差分から重要事項を抽出すること．
4. 文字，矢印，囲み，因果図，比較図，簡易概念図を描くこと．
5. 整ったデジタルインク風と，より手書き風を初版から選べること．
6. スライドの空白領域だけを使い，既存内容に重ねないこと．
7. 講師のペンタブ入力を常に優先すること．
8. 判断に迷う場合は講師を止めず，何も書かずに待つこと．
9. 学生には確定済みの安定した板書だけを見せること．
10. 講義後に，PowerPointとAI板書と講師手書きを対応付けて保存すること．

## 11．標準プリセット案

### A．日本語講義・標準

- 入力言語：日本語優先，自動切替あり
- 出力言語：発話と同じ言語
- 描画：整ったデジタルインク風
- 板書量：少なめから標準
- 図式化：中程度
- 不確実時：書かずに待つ

### B．英語講義・標準

- 入力言語：英語優先，自動切替あり
- 出力言語：英語
- 描画：整ったデジタルインク風
- 板書量：標準
- 図式化：中程度
- 専門語：原語を保持

### C．日英混在講義

- 入力言語：自動
- 出力言語：発話と同じ言語
- 日英併記：重要語のみ
- 描画：選択可能
- 不確実時：後続文脈を待つ

## 12．設計上の結論

LectureBoard AIは，講師の命令を待つ道具ではなく，講義を静かに理解し，必要なときだけ余白へ書き加える「非介入型の共同板書者」として設計する．

講師は通常どおり話し，必要な場合だけペンタブで加筆する．AIは，スライドと講義文脈から重要事項を判断し，文字または図形として，選択された描画スタイルと言語設定に従って提示する．
