# 開発ロードマップ

## M0：GitHub公開可能な基盤

状態：本リポジトリに初期実装あり．

- macOS-firstの技術設計
- Swift Package
- 文脈判断プロトコル
- 規則ベース参照実装
- 余白配置
- SwiftUIデモ
- 日本語・英語モデル
- JSON保存
- 単体テスト
- CI，Issue，PR，Security文書

完了条件：`swift test`が通過し，公開前チェックリストが確認される．

## M1：実音声プロトタイプ

- 入力マイク選択
- 音声認識権限
- 日本語／英語認識
- 確定・未確定発話の分離
- 文末・無音による意味単位分割
- 音声強調の簡易特徴
- 講義中の言語切替

完了条件：10分の録音音声で，途中結果を学生に見せず，確定文だけが板書判断へ送られる．

## M2：PowerPoint映像統合

- ScreenCaptureKitウィンドウ選択
- PowerPoint Slide Showの連続取得
- スライド変化検出
- Vision OCR
- 占有領域・空白マップ
- 合成出力ウィンドウ

完了条件：PowerPointの既存文字・図へ重ならず，Zoom等で一つの共有ウィンドウとして表示できる．

## M3：ペンタブ

- AppKitタブレットイベント
- 筆圧・傾き
- AI板書とは独立した人間インク
- 人間占有領域
- 消しゴム
- 取消し

完了条件：講師の線が低遅延で表示され，AIがその領域を避ける．

## M4：高度な板書AI

- ローカル／クラウドプロバイダ
- JSON Schema出力
- 出典拘束
- 文字／図形選択
- 日英用語集
- 個人適応
- 取消しからのローカル学習

完了条件：実講義評価で板書しすぎを抑えつつ，中心的定義・因果・比較を高精度に抽出する．

## M5：β版

- 講義後編集
- PDF，SVG，PNG，Markdown

- 外部ディスプレイ検証
