# 文脈から重要事項を判断する板書エンジン設計

## 1．目的

LectureBoard AIの中心は音声認識ではなく，「講師が今説明している内容のうち，学生の理解のために何を残すべきか」を判断する機能である．

本機能は，音声命令を待たない．講師が通常どおり講義している間に，自律的に判断する．

## 2．判断単位

音声認識の部分結果をそのまま板書しない．次の条件で「意味単位」を確定する．

- 句点または明確な文末
- 650〜1200 ms程度の発話間隔
- 定義・列挙・因果説明の完結
- スライド切替直前
- 同じ主題から別主題への遷移

短すぎる断片は，後続発話へ結合する．

## 3．入力文脈

### 3.1 現在スライド

- タイトル
- OCR文字
- 図表占有領域
- スライド言語
- 前スライドとの差

### 3.2 発話

- 確定文字起こし
- 言語
- 認識確信度
- 開始・終了時刻
- 発話速度
- 間
- 音量・強調の補助指標

### 3.3 講義履歴

- 直近の発話
- 既出の中心概念
- 前に定義された用語
- 既存板書
- 取消された板書
- 講師の手書き

## 4．重要度特徴

重要度`I`は，概念的には次の合成で求める．

```text
I = 新規性
  + 定義性
  + 関係構造
  + 反復・言い換え
  + 教育的中心性
  + 音声上の強調
  + 後続説明への必要性
  - スライドとの過剰重複
  - 既存板書との重複
  - 認識不確実性
  - 雑談・フィラー
  - 板書過密
```

初期の規則ベース実装は，この考え方をテスト可能にした参照実装である．将来のモデル実装も，同じ説明可能な特徴と出典を返す．

## 5．強い板書候補

### 定義

```text
「XとはYである」
“X means Y.”
“X is defined as Y.”
```

原則として`definition`要素を生成する．

### 因果

```text
A．そのため，B．
A；therefore，B．
A leads to B．
```

二段階なら矢印，三段階以上なら因果連鎖を選ぶ．

### 比較

```text
Aである．一方，Bである．
A，whereas B．
A rather than B．
```

空白が十分なら二列比較，不足する場合は上下比較とする．

### 列挙

三点以内は箇条書き．四点以上は，階層化できる場合だけまとめる．単に長いリストを作らない．

### 中心的な問い

講義の中心となる問いは，答えより先に短い問いとして残すことがある．修辞疑問をすべて板書しない．

## 6．板書しないもの

- 「ええと」「それでは」等のフィラー
- 画面操作の独り言
- スライドに明記された一文の単純な読み上げ
- 学生の個人名や個人情報
- 不確かな数値・年号・固有名詞
- 出典のないAI補足
- 同じ内容の言い換えを何度も繰り返すこと
- 講師が雑談として扱っている内容

## 7．文字か図形か

```text
単独概念・短い定義 → 文字＋下線／囲み
二項対立 → 比較図
原因と結果 → 矢印
三段階以上の因果 → 因果連鎖
上位・下位 → 階層図
複数概念の相互関係 → 概念マップ
手順・時間 → フロー
```

図形を選んでも，ノード内の語句は短くする．

## 8．安定化

### デバウンス

同じ説明単位の途中で何度も書き換えない．候補ができても，短い保留期間を置いて後続文で確定する．

### クールダウン

標準では，板書追加後に一定時間，新しい低重要度候補を抑制する．

### 固定

表示から一定時間経過した要素，または講師が固定した要素は自動差替えしない．

### 訂正

誤りを訂正するときは，元要素との関連を保持し，画面全体の再配置を避ける．

## 9．根拠保持

各板書要素には，次を記録する．

- 元発話セグメントID
- 元発話
- 現在スライドID
- 判断理由
- 重要度
- 認識確信度
- 使用したモデル／規則版
- 自動生成・講師修正・講師手書きの区分

講義後，講師は板書の根拠を確認できる．学生側には通常表示しない．

## 10．生成モデル接続時の契約

モデルには自由な文章を書かせず，JSON Schemaに従う出力を要求する．

必須制約：

- `sourceSegmentIds`が空の要素を学生へ表示しない
- 原発話にない数値・人名・引用を追加しない
- `confidence`が閾値未満なら保留
- 未知の図形型をレンダラーへ渡さない
- テキスト長，ノード数，矢印数を制限する
- 翻訳時も原語を保持する

## 11．評価指標

### 内容選択

- Precision：表示した板書のうち，講師が必要と判断した割合
- Recall：講師が必要と判断した板書を拾えた割合
- Overboarding rate：板書しすぎ
- Missed-critical-point rate：重大要点の見落とし

### 表現

- 文字／図形選択の妥当性
- 要約による意味変化
- 読了可能時間
- 既存スライドとの重なり
- 講師手書きとの衝突

### 講義体験

- 講師がAIを意識せず話せたか
- 取消し回数
- 学生の視線負荷
- ノート取得支援

## 12．個人適応

将来，講師ごとに次を学習できる．

- よく板書する表現
- 定義を残す頻度
- 図形の好み
- 板書量
- 日英併記方針
- 取消し傾向

ただし，個人適応データはローカル保存を標準とし，明示的同意なく共有学習へ使用しない．
