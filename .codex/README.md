# Local Codex configuration

This directory contains conservative project defaults for working on LectureBoard AI with Codex on macOS.

- Codex may read, edit, build, and test files inside this repository.
- Access outside the repository or outbound network use should require an explicit decision.
- GitHub publication remains a separate, deliberate action.

After opening this repository in the ChatGPT desktop app under **Codex**, trust the project only after reviewing `AGENTS.md` and this configuration.
